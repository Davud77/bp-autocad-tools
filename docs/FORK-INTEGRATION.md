# Перенос функций AutocadTools

Источник: [OOXGN-OOX/AutocadTools](https://github.com/OOXGN-OOX/AutocadTools), коммит `f662abe4830e1a2a270dfaa1aad35b360f0b6192` от 28.10.2026. Наша исходная версия: 1.7.1, коммит `5df00d4`.

| Область | Результат интеграции |
| --- | --- |
| Новые инструменты | Копирование с нумерацией, каталог обозначений, разрезы и разрывы |
| Копирование | Траектории и режим сегментов; атрибуты, группы, ПСК и Undo |
| Аксонометрия | Исправления TEXT/MTEXT и перемещённых атрибутов |
| Штамп | Полные свойства, длинные поля, типографика по WM_FORMAT, библиотека подписей и встроенная геометрия DWG |
| Команды | AT/АТ, редактор PGP; сохранены все 24 прежних имени и добавлен русский вариант сброса TABLE |
| Обновления | Сохранён наш встроенный прогресс и SHA-256, добавлена отложенная установка с отменой |
| Интерфейс | Сохранена наша тема AutoCAD, адаптивный штамп; классика выключена по умолчанию |
| Значки | 24 различных изображения для 24 кнопок, десять новых авторских рисунков; исходники в scripts/Build-Icons.ps1 |
| Справка | docs/USAGE.md адаптирован под BotPlus, корневой USAGE.md ведёт к нему |

Наши более новые возможности сохранены: CTB/STB, единицы чертежа и вставки, прозрачность PDF, калькулятор, сброс зачёркивания и стиля TABLE, встроенная панель обновлений. Протяжка номеров листов уже была у нас и повторно не переносилась. Оформление и бренд форка заменены нашим интерфейсом; новые пиктограммы нарисованы отдельно.

Проверки: сборки AutoCAD 2025–2027, обычный набор scripts/Test.ps1, native smoke AutoCAD 2026/2027, отдельные проверки новых инструментов scripts/Test-ForkFeatures.ps1, жизненный цикл классического интерфейса в DesktopChecks, проверка отложенного установщика без запуска настоящего EXE. Результаты проверок и ограничения выпуска: [VALIDATION.md](VALIDATION.md).
