# BotPlus AT 1.10.0

Новый единый набор иконок для ленты и классической панели. Иконки следуют теме AutoCAD: для тёмной темы — светлые линии, для светлой — тёмные. Смена темы применяется сразу.

![Иконки BotPlus AT в тёмной и светлой теме](assets/icons.png)

Окна «Очистка чертежа» и «Выбор по образцу» запоминают все флажки. Команды и их поведение не изменились.
