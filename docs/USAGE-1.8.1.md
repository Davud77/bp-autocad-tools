# BotPlus AT 1.8.1

По умолчанию вставка и печать — 1:100, открытие папки PDF включено, фон выключен, поиск листов слева направо. При первом запуске после обновления эти значения применяются один раз, затем пользовательские изменения сохраняются.

Исправлены макросы классического интерфейса (управляющие ASCII-символы вместо текста ^C^C), фон BMP-значков и кэш 16/32 px. Старое меню 1.8 скрывается, создаётся исправленное 1.8.1. Устаревший отсутствующий путь QNEW к botplus.dwt заменяется на шаблон установленного bundle после загрузки плагина.
