# BotPlus AT 1.9.0

Выпуск о производительности: плагин больше не работает в фоне постоянно, поэтому зависания и микрофризы при обычной работе в AutoCAD должны уйти.

## Штамп

- Слежение только за форматкой `WM_FORMAT`. Перенос, копирование и правка других блоков плагин не трогает.
- Подписи и переносы длинных полей проверяются один раз после команды, в которой менялась форматка, после `РЕГЕН`, `РЕГЕНВСЕ`, `ОБНПОЛЕ`, `СВОЙСТВАЧЕРТЕЖА` и перед сохранением. Ежесекундной проверки больше нет.
- Чертежи без форматки не отслеживаются. Рамки ищутся по ссылкам блока, а не перебором всего чертежа. Поля пересчитываются только при изменении свойств DWG.
- Подписи не распаковываются заново, если их блок уже есть в чертеже. Хранилище подписей читается повторно, только когда оно изменилось.

## Сумма длин в строке состояния

- Левый клик по полю копирует значение в буфер обмена.
- Правый клик — меню «Включить/Выключить подсчёт длины». В выключенном состоянии плагин не отслеживает выделение и ничего не считает. Выбор сохраняется.
- Выделения больше 5000 объектов считаются по клику, а не автоматически.
- При открытом окне «Сумма длин» расчёт не выполняется дважды.

## Интерфейс

- Одновременно показывается один интерфейс: при включённом классическом режиме — меню и панель (вкладка ленты убирается), при выключенном — только вкладка ленты. Переключение применяется без перезапуска.
- Лента и меню проверяются только при запуске, смене рабочего пространства, перезагрузке CUI и изменении настройки, а не раз в секунду.
- Кнопки ленты обновляют доступность только при открытии, закрытии и переключении чертежей.

## PDF-плоттер

- Установка «BotPlus PDF» запоминается для каждой версии AutoCAD. Пути определяются через AutoCAD на конкретном ПК. Если версия плагина, профиль или файлы не изменились, при запуске ничего не делается.
- При ошибке установки повторов каждую секунду больше нет.
