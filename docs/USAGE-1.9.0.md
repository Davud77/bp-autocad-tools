# BotPlus AT 1.9.0

Плагин больше не работает в фоне постоянно. Штамп проверяется только после изменения форматки `WM_FORMAT`, после `РЕГЕН`, `РЕГЕНВСЕ`, `ОБНПОЛЕ`, `СВОЙСТВАЧЕРТЕЖА` и перед сохранением.

Поле «Сумм. длина» в строке состояния: левый клик копирует значение, правый — включает или выключает подсчёт. Выключенный подсчёт не нагружает AutoCAD.

Классический режим заменяет вкладку ленты, выключенный — показывает только ленту. Установка PDF-плоттера запоминается.
