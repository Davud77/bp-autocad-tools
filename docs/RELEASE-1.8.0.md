# BotPlus AT 1.8.0

Перенесены инструменты из [AutocadTools / OOXGN](https://github.com/OOXGN-OOX/AutocadTools):

- Копирование с нумерацией по точкам, кривым и вершинам, с выбором числового фрагмента.
- Каталог условных обозначений, прямые и ступенчатые разрезы, обрывы и разрывы.
- Мультикопирование вдоль кривой, сохранение атрибутов и групп; исправления аксонометрии текста.
- Штамп: длинные поля до 1000 символов, переносы по ячейкам, PNG и рукописные подписи, встроенные в DWG.
- Полные команды AT… / АТ… и окно настройки сокращений acad.pgp с проверкой конфликтов и резервной копией. Все прежние команды сохранены: всего 77 имён.
- Отложенная установка проверенного обновления после закрытия всех AutoCAD, по отдельной галочке.

Классический интерфейс по умолчанию выключен. Его включает только галочка **Сервис → Интерфейс → Загружать классическое меню и панель**. При отключении меню и панель скрываются безопасно, без удаления живых объектов интерфейса AutoCAD.

Созданы десять новых значков: импорт, экспорт, сброс таблицы, форматка, библиотека, копирование с нумерацией, обозначения, разрез, разрыв и сокращения. Снимок ленты и полное [руководство](USAGE.md) добавлены в репозиторий.

Ссылки проекта и проверки обновлений переведены на Davud77/bp-autocad-tools. Наши CTB/STB, единицы чертежа, прозрачность печати, калькулятор и очистка стилей TABLE сохранены.
